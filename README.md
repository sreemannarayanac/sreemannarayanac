# Sreemannarayana Chamarti — Portfolio

A minimal, clean portfolio website built with **React**, **Vite**, **plain CSS**, and **Framer Motion**.

## Features

- 🌗 Dark / Light mode toggle (persisted via localStorage)
- 🎞️ Smooth scroll-reveal animations (Framer Motion)
- 📱 Fully responsive design
- ⚡ Fast builds with Vite

## Local Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev
```

The site will be available at `http://localhost:5173`.

## Build for Production

```bash
npm run build
```

## Deploy to GitHub Pages

```bash
npm run deploy
```

This runs `vite build` and then publishes the `dist/` folder to the `gh-pages` branch.

The live site will be available at:  
**https://sreemannarayanac.github.io/my-portfolio**

## Tech Stack

| Layer     | Technology          |
| --------- | ------------------- |
| Framework | React 18            |
| Bundler   | Vite 6              |
| Styling   | Plain CSS (custom properties) |
| Animation | Framer Motion       |
| Hosting   | GitHub Pages        |
